Big Five Personality InventoryFor instructors

Build class norms

Turn your students’ result files into norms based on your own class, so percentiles compare each student with peers instead of with adults of all ages. Files are read in this browser tab and never uploaded.

Add result files

Add the CSV files students downloaded from the inventory. Individual files, a spreadsheet you’ve already combined, and files from earlier semesters all work. Duplicate submissions are detected and counted once.

    What was found

    Save the combined data to keep a running file you can add next semester’s results to, for larger and more stable norms. It contains only response IDs, item set, course, date, and the 30 answers.

    Class averages

    Scores are on the 1–5 response scale. The last column shows how far your class average sits from the built-in adult norms, in standard deviations. Small differences of 0.2 or less are typical noise.

    Your new norms

    1. Copy the block below.

    3. Find the block that begins with const NORMS = { and ends with };, and replace all of it with what you copied.
    4. Commit the change. The live page updates within a minute or two.
